## מיפוי משתנים
| משתנה | ערך |
|---|---|
| `{CONTEXT}` | `./context/` |
| `{OUT}` | `./<namespace>/` |

## הפעלה
```
קרא agents/<id>.md ופעל לפיו.
טען את קבצי ההקשר ברשימת context שבראש הקובץ.
כתוב ל-{OUT}.
```

## מה רץ כאן ולמה
| סוכן | סיבה |
|---|---|
| auditor | הסקילים שלך כאן, ועברית טובה יותר |
| producer | הפלט מזין את hebrew-docs-engine |
| amplifier | הקול שלך נמצא כאן |
| **כל סינתזה שלא דורשת גלישה** | **לא עולה מכסת Grok** |

## הכלל המרכזי לחיסכון
**מה שלא דורש דפדפן - לא רץ על גרוקבוט.**
אם המכסה בלחץ, העבר את הסינתזה השבועית של scout לכאן. היא קוראת קבצים מהריפו ואינה צריכה רשת.
