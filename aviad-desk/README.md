# aviad-desk

תשתית סוכנים אישית. **אגנוסטית לספק ולמודל.**

## עקרון התכנון

הכלי מתחלף. ההקשר נשאר.

```
context/     מי אני, מה אני טוען, מה פתוח - קורא כל סוכן
agents/      הגדרת תפקיד ניטרלית - לא תלויה בפלטפורמה
runners/     שכבת ההתאמה - איך מריצים על גרוקבוט / Claude Code / כל דבר אחר
schemas/     חוזי פלט - JSON Schema, ניתנים לוולידציה
<namespace>/ תוצרי הסוכנים
feedback/    אותות הפידבק שלך
```

**הכלל:** קובץ ב-`agents/` לעולם לא מזכיר `workspace/`, `git push`, שעה, או שם ספק.
כל זה יושב ב-`runners/`. להחליף ספק = להחליף קובץ אחד ב-`runners/`.

## החלפת מנוע

| רוצה להעביר סוכן ל... | מה משתנה |
|---|---|
| Claude Code / Cowork | `runners/claude-code.md` |
| מנוע אחר בעתיד | קובץ חדש ב-`runners/` |
| **מה לא משתנה** | `context/`, `agents/`, `schemas/`, כל התוצרים |
