```bash
git fetch origin --prune -q
for r in origin/main origin/claude/autonomous-workers-routine-hna6je; do git cat-file -e "$r:aviad-desk/scripts/desk.sh" 2>/dev/null && git checkout "$r" -- aviad-desk/scripts/ && break; done

```

הפקודה נכשלה - **עצור, דווח, אל תתקן ידנית ואל תמשיך לעבוד.**

## שלב 2 - קרא `aviad-desk/RUN.md` ופעל לפי שבעת השלבים שם, במדויק.
הנחיית התפקיד שלך היא `aviad-desk/agents/relations.md`. טען מ-`aviad-desk/context/` **רק** את הקבצים שבריף הריצה הדפיס.

## שלב 3 - משימת הריצה

**מפת כוח, לא רשימת תזכורות.**

תחזק תיק ב-`aviad-desk/people/files/<slug>.md` לכל אדם ב-`context/people.md`:
תפקיד ומיקום ארגוני | **תפקיד במערכת ורמת מחויבות** (עניין / מחויבות / ספונסרשיפ / בעלות) |
מה מניע אותו מהחומר הפומבי | היסטוריית מגע | התנגדויות ידועות | מה הוא צריך ממני ומה אני ממנו | ימים מאז מגע אחרון.

**חוק: אל תדווח על "תמיכה" בלי לציין את רמת המחויבות. עניין אינו מחויבות.**

דוח שבועי `aviad-desk/people/weekly-{WEEK}.md`: מי פרסם משהו רלוונטי | מי חצה סף התקררות
(30 יום מטה ומערך, 45 יום אחרים) | שלוש פניות מוצעות עם נימוק ורמת המחויבות הנוכחית.

**אתה לא פונה לאף אדם. הצעת פנייה היא שורה בדוח, לא פעולה.**
מקור שדורש התחברות - רשום "חסום", דלג, המשך. **אין דפדפן מאומת בענן.**
