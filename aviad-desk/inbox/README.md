# inbox - ההזנה הידנית

לכאן אביעד מעתיק פלט מכלים שאינם חלק מהמערכת: Gemini Deep Research, ChatGPT, סיכומי פגישות מ-Summit,
תמלולים, מסמכים שהתקבלו. `chief-of-staff` קורא מכאן ומחלץ החלטות, התחייבויות, חוסמים ושינויי סטטוס.

## חשוב - למה הענן לא רואה את זה כברירת מחדל

`.gitignore` מתעלם מ-`inbox/*`. זה מכוון: התיקייה עלולה להכיל חומר גולמי שלא נועד לריפו.
**המשמעות: עובד שרץ בענן רואה inbox ריק, אלא אם דחפת קובץ במפורש.**

לדחוף פריט אחד לעיבוד בענן:

```bash
git add -f aviad-desk/inbox/2026-09-01-סיכום-ישיבה.md
git commit -m "inbox: סיכום ישיבה" && git push
```

**לפני שאתה דוחף:** לא נתוני ביטוח לאומי, לא מידע על אזרחים, לא מסמכים פנימיים שלא פורסמו,
לא טלפונים וכתובות פרטיות. אותו כלל כמו `context/`.

הבריף היומי עובד גם בלי inbox - הוא נבנה מ-`calendar.md`, מ-`radar/open.json` ומתוצרי העובדים האחרים.
inbox מוסיף לו את שכבת ההתחייבויות והחוסמים.
