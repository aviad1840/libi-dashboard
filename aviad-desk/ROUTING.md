# ניתוב משימות בין הכלים

**התובנה המרכזית:** אי אפשר לגרום לסוכן להפעיל את המנויים האישיים שלך. ל-ChatGPT Go, ל-Gemini האישי ול-Claude chat **אין גישה תכנותית**. כל תכנון של "סוכן שמתזמר את כל הכלים שלי" יישבר.

**מה כן אפשרי, ושווה יותר:** שכל כלי יתחיל **חם** מאותו הקשר. `context/_index.md` הוא כ-800 טוקנים - הדבק אותו כהוראות פרויקט בכל כלי שאתה מפעיל ידנית.

## הדבקה חד-פעמית
| כלי | איפה |
|---|---|
| ChatGPT | Project instructions |
| Gemini | Gem / הוראות מותאמות |
| Claude | Project knowledge |
| Claude Code | `CLAUDE.md` בשורש הריפו |

מעכשיו כל כלי יודע מיהו C1, מהי OQ2, ומהו AP2 - **בלי שתסביר שוב.**
