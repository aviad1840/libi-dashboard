# פורמט פידבק

**קובץ, לא צ'אט.** צ'אט הוא מנגנון תלוי-ספק. קובץ עובד בכל מנוע.

`feedback/YYYY-MM.md`, שורה אחת ביום:

```
2026-09-01  +03 +07 !!11 -01 -02 -05
```

| סימן | משמעות |
|---|---|
| `+` | מועיל |
| `-` | רעש |
| `!!` | שינה החלטה או פתח הזדמנות |

**30 שניות ביום. זה כל מה שנדרש כדי שהמערכת תלמד.**

## אותות אוטומטיים (בלי עלות)
- הזדמנות שסטטוסה הפך ל`הוגש` = `!!`
- קובץ ראיות שנכנס למסמך שהופק = `+`
- דוח שלא נפתח שבוע = אות שלילי לסוכן כולו

## פידבק גולמי מ-gateway (טלגרם) - `feedback/queue/YYYY-MM-DD.jsonl`

זה **לא** מחליף את הפורמט החודשי למעלה - `curator` מקפל את שניהם יחד. הבדל: כאן הפידבק
נשמר **גולמי, לפני סיווג**, שורה אחת ל-JSON, כדי לא לאבד הקשר (על איזה פריט, ממי, ובאיזו מילה).

```json
{"timestamp":"2026-09-01T18:03:00Z","agent":"scout","artifact":"I-20260901-03","feedback_type":"output_feedback","raw_feedback":"👍","context":"ממצא על מכרז מערך הדיגיטל","source":"telegram","confidence":"high"}
{"timestamp":"2026-09-01T18:05:00Z","agent":"advocate","artifact":"C1","feedback_type":"correction","raw_feedback":"זה לא נכון, הראיה מ-2024 לא 2025","context":"תיק הראיות ל-C1","source":"telegram","confidence":"high"}
```

| שדה | מה |
|---|---|
| `timestamp` | UTC, ISO 8601 |
| `agent` | מי הפיק את הפריט - הסק מקידומת `artifact`: `I-`→scout, `C<n>`→advocate/curator, קובץ ב-`people/`→relations, וכו' |
| `artifact` | הפניה מדויקת לפריט (מזהה, לא תיאור) |
| `feedback_type` | אחת משש הקטגוריות למטה |
| `raw_feedback` | הציטוט המקורי, מילה במילה - לא פרפרזה |
| `context` | שורה אחת - על מה זה נאמר, אם לא ברור מ-`artifact` לבד |
| `source` | תמיד `telegram` בשלב הזה |
| `confidence` | `high`/`medium`/`low` - כמה בטוח הסיווג של `feedback_type` |

| `feedback_type` | מתי |
|---|---|
| `output_feedback` | 👍👎🔥🔎❌💡 או "שימושי"/"רעש"/"חשוב"/"לא רלוונטי" - על תוצר קיים |
| `correction` | תיקון עובדתי מפורש ("זה לא נכון ש...") |
| `preference` | העדפה כללית, לא על פריט ספציפי ("שים יותר דגש על X", "אל תציג דברים כאלה") |
| `context_change_request` | בקשה מפורשת לשנות קובץ ב-`context/` |
| `decision_change` | שינוי החלטה על מסלול/טענה |
| `temp_instruction` | הוראה חד-פעמית ("תבדוק את זה מחר") - לא קבועה |

**חוק ברזל, זהה לזה של curator:** שום `feedback_type` לא הופך אוטומטית לשינוי ב-`context/`.
**אסור להסיק העדפה קבועה מאירוע יחיד.** curator הוא היחיד שמכייל, ורק עם ראיה חוזרת, ורק עם
מספר מדויק של חזרות (ראה `routines/curator-weekly.md`) - "רושם" אינו ראיה.
